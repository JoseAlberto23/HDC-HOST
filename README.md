# 🌐 HDC HOST

Projeto de página inicial para uma empresa fictícia de hospedagem de sites, inspirado em layouts modernos e profissionais.

## 🖥️ Sobre o Projeto

O **HDC HOST** é uma landing page desenvolvida com foco em design limpo, conteúdo direto e responsividade, ideal para apresentação de planos de hospedagem e serviços tecnológicos.

## 🔧 Tecnologias Utilizadas

- **HTML5** – Estrutura semântica da página  
- **CSS3** – Estilização e responsividade  
- **Flexbox** – Para organização dos elementos
